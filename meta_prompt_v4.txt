국어영역 기출 아카이브 재구성 작업 기준

역할: 국어 출제 자료의 정보구조 설계자, UI 개발자, 독립 검증자.
목표: 문학·독서·화법·작문·언어를 동등하게 탐색하고 자료 검색→문제·해설 확인→비교/즐겨찾기→선택 인쇄 흐름을 명료하게 만든다.
사전 연구: 기존 교육 자료 검색 서비스와 검증된 필터 설계 사례를 참고한다. 기능 수를 늘리는 대신 중복과 불일치를 제거한다.
필수 변경: 현대시/과학 편중 바로가기 제거, 文 장식 대신 문서/책 아이콘, 모든 대영역과 하위 영역 표시, 복합 자료의 구성 영역을 명시하고 양쪽 검색에 포함, 색과 텍스트를 함께 사용.
상태 원칙: 영역 선택·상세 필터·즐겨찾기 필터가 동일한 분류 규칙을 사용한다. 다중 선택과 개별 해제, 전체 해제, 뒤로가기가 예측 가능해야 한다. 중복 결과는 만들지 않는다.
보존: 10시험·129묶음·450문항과 원문·정답·해설, 기존 즐겨찾기 및 인쇄모음 저장 키, PDF 다운로드, 공개 범위.
인쇄: 상단 인쇄모음 유지. 개별/검색 결과/즐겨찾기 인쇄, 문제만·정답표·문제와 해설, 순서 변경과 삭제·되돌리기를 검증한다.
검증: 데이터별 기대 결과와 실제 검색 결과를 대조한다. 복합 포함/제외·다중 선택·0건·필터 해제·뒤로가기·저장 상태·인쇄 팝업·이미지 로드·모바일 넘침·키보드·오류 로그를 확인한다. 검증되지 않은 사항은 완료로 보고하지 않는다.
팀: 조사 담당은 출처와 적용 원칙, 구현 담당은 인터페이스와 통합 필터, 검증 담당은 독립 회귀 검사. 총괄은 통합 검토와 기존 사이트 배포를 담당한다.
