출력 전용 페이지 개발 기준
목표: 교사가 자료 탐색과 별도로 시험·영역·갈래를 선택하고 해당 문제와 해설을 한 번에 인쇄하거나 PDF로 저장한다.
구조: 조건 선택 → 출력할 자료 확인·제외 → 구성 선택 → 인쇄 미리보기.
규칙: 문학·독서·화법·작문·언어 동등, 통합 자료는 구성영역에서 검색, 동일 자료 중복 금지. 조건 내 여러 값은 합집합, 시험과 영역 등 서로 다른 조건은 교집합.
출력: 기존 원문 출력 엔진을 재사용. 문제만·정답표·문제와 해설, 표지·분석, 제목·순서 선택 지원. 브라우저 인쇄 대화상자에서 PDF 저장 가능함을 명확히 안내.
보존: 원문/정답/해설 데이터 및 기존 즐겨찾기·인쇄모음 유지. 전용 페이지 설정은 별도 저장.
검증: 예상 키목록과 실제 필터 비교, 개별 제외·재선택·전체해제·복원, 실제 미리보기 문항·해설·이미지 및 넘침, 모바일, JavaScript 오류, 기존 주요 기능 회귀.
역할: 구현 담당은 booklet 3파일, 검증 담당은 독립 검사, 총괄은 메뉴 연결·시각 검토·배포.
