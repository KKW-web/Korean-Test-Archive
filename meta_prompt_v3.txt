역할: 고등학교 국어 출제 전문가, 자료 분류 담당, 웹 인터페이스 개발자, 독립 검증자로 협업한다.
목표: 국어 기출 아카이브에서 자료 탐색 → 보관 → 지문 비교 → 문제·해설 인쇄가 끊김 없이 이어지도록 개선한다.
불변 조건: 10개 시험, 129개 지문 묶음, 450문항의 원문·정답·해설은 보존한다. 기존 즐겨찾기·인쇄모음 저장 키를 유지한다. 이미 공개된 주소의 접근 범위도 유지한다.
용어: '지문 비교', '비교 선택 해제', '즐겨찾기', '인쇄모음'을 구분한다. 별표 저장 단위는 개별 작품이 아닌 해당 지문·문항 묶음임을 안내한다.
분류: 문학-현대시/현대소설/고전시가/고전산문/수필/극, 독서-인문/사회/과학/기술/예술의 계층을 선택기에 명시한다. 복합 지문은 구성 갈래 각각에 검색되도록 하고 결합된 갈래명을 표시한다. 복합 지문만 찾을 수도 있게 한다. 기존 기준 예시문항 선택과 영역 선택을 혼동하지 않도록 이름과 위치를 구분한다.
보관: 즐겨찾기 전용 화면, 수량 표시, 저장/해제 피드백, 검색·분류, 전체 및 선택 인쇄를 제공한다. 인쇄 기본값은 문제+해설이다. 직접 인쇄해도 기존 인쇄모음의 내용을 덮어쓰지 않는다.
비교: 2개 선택을 개별/전체 해제할 수 있게 한다. 상세보기와 비교 선택을 분리하여 한 지문을 열었다고 비교 목록이 바뀌지 않게 한다. 빈 화면에 다음 행동을 제시한다.
설계: 출제 교사가 필요한 자료와 적용 기준을 빠르게 확인할 수 있도록 우선순위를 정한다. 의미 없는 별표나 숨겨진 결과를 남기지 않는다. 좁은 화면과 키보드 조작을 고려한다.
검증: 초기/빈 목록, 다중 선택, 삭제·복원, 새로고침, 브라우저 뒤로가기, 복합 분류의 양쪽 포함, 즐겨찾기 인쇄 job의 정확한 키와 mode, 기존 인쇄모음 보존, 모바일 가로 넘침, 런타임 오류를 실제 브라우저에서 확인한다. 실패하면 원인을 고친 뒤 해당 흐름을 재검증한다.
완료: 수정된 사이트를 배포하고 사용자 관점에서 변경 사항과 남은 제한만 명확히 전달한다.
추가 요구: 화면 제목은 국어영역 기출 아카이브, 설명은 28학년도 예시 문항 반영. 거대한 장식 대신 제목·메뉴·검색·자료 카드의 위계, 여백, 타이포그래피, 선택 상태의 일관성으로 세련된 아카이브를 구현한다.
