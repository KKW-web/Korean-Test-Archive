2028 국어 문항 비교실 개선 메타프롬프트 v2

목표
전체 국어 자료를 유지하되, 현대시를 비롯한 세부 영역으로 빠르게 탐색하고 여러 시험의 원하는 지문·문제를 골라 출제 참고용 자료집을 만드는 작업 흐름을 구현한다.

팀
- 총괄: 사용자 과학 자료집의 편집방식 확인, 실제 서비스 UX 조사, 데이터 통합, 인쇄 미리보기와 결과물 배포.
- 분류 검증: 129세트의 문학 갈래·독서 세부영역 원문 확인, 복합갈래 구성 요소별 중복 검색.
- 원문 편집: 지문세트 경계·페이지·단 좌표를 확인하여 문제 이미지 절취. 지문, 보기, 도표, 선지 누락 방지.
- UI 구현: 다중 조건, 인쇄 모음, 순서 조절, 탐색 복원, 비교·정답 보기, 반응형 디자인.
- 독립 QA: 분류/정답/문항누락/출력범위/사용성 회귀 확인.

설계 원칙
1. 문학: 현대시, 현대소설, 고전시가, 고전산문, 수필, 극. 갈래 복합은 구성 갈래를 구체적으로 표시한다. 현대시 검색에서 현대시가 포함된 복합세트도 찾되 사용자가 복합포함 여부를 선택할 수 있게 한다.
2. 독서: 인문·사회·과학·기술·예술. 공식 분류와 세부 소재 성격을 함께 보존한다. 과학·기술이 겹치는 자료는 누락 없이 검색한다.
3. 같은 조건 그룹 내 선택은 OR, 서로 다른 그룹은 AND. 선택 조건을 화면에 명확히 표시하고 개별 해제 및 전체 해제를 제공한다.
4. 두 세트 비교와 제한 없는 인쇄 모음을 구분한다. 검색결과 전체 담기, 개별 선택, 중복 제거, 순서 이동, 삭제 취소를 제공한다.
5. 문제만 / 정답표 / 문제+해설을 골라 인쇄 미리보기를 만든다. 분석설명·표지는 선택 사항이다. 원본 시험번호와 출처를 유지한다.
6. 가능한 경우 관련 지문세트만 절취한다. 경계 확인이 어려운 자료는 원문페이지를 보존하고 인접 문항 포함 여부를 명시한다. 원문을 임의로 재작성하지 않는다.
7. 정답해설 원문은 누락 없이 제공한다. 인쇄에서 같은 원문 해설 페이지가 반복되지 않도록 처리한다. 설명은 원문과 별도로 표시한다.
8. 목록으로 돌아오면 검색조건·선택·스크롤이 유지되도록 한다. 브라우저 뒤/앞가기와 충돌하지 않도록 한다. 빈결과, 선택없음, 이미지로딩 실패, 저장 실패도 처리한다.
9. 첫 화면의 장식보다 검색·비교·인쇄 작업을 우선한다. 색·간격·타이포그래피·상태표시를 일관되게 유지한다. 모바일에서도 조작 가능해야 한다.

검증
- 전체 10시험/450문항/129세트가 유지되는지 확인.
- 현대시 단독 및 복합 검색을 원문과 대조.
- 두 시험+현대시 등 교차 조건, 결과전체담기/선택해제, 인쇄순서, 삭제취소 검증.
- 문제만 출력에 정답이 노출되지 않는지, 선택하지 않은 세트가 섞이지 않는지 검증.
- 인쇄 미리보기와 실제 PDF 렌더링으로 잘림·공백·누락·페이지순서 확인.
- 기존 비교/정답펼침/원문확대/즐겨찾기 기능 회귀 검증.
